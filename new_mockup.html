User Variables

Use predefined shared variables across connected chatbot domains.

Built-in Variable

Predefined variables are automatically saved and reused during domain transfer.

Type Built-in variable name Description / Example
Character string *cicRequest.session.callInfo.callee Saves the recipient’s number.
“01012341234”
Character string *cicRequest.session.callInfo.caller Saves the sender’s number.
“01012341234”
JSON *transferDomain.domainCode Saves the previous domain code.
“abc.aicall”
JSON *transferDomain.userVariables Carries shared user variables from the previous chatbot domain.
{ "isMobile": null, "phoneNumber": null }
↔
Shared Context
Built-in variables preserve caller information, domain code, and shared user data when moving between chatbot domains.
